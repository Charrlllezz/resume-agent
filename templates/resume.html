What happens next

The document is transcribed into structure — not rewritten. Nothing is invented, no bullets are improved, no metrics are added.

Then every extracted bullet is traced back to the document by string comparison, and every number in it is checked against the document's numbers. Anything that doesn't trace is flagged.

Then you review and edit it, and only then is it saved. That last step isn't ceremony: the QA layer certifies tailored output by comparing it to this file, so if a model wrote it unsupervised the fabrication check would be marking a machine's homework.
